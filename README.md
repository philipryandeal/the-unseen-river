# The Unseen River

A river built blind. Thirteen intelligences each build one stretch, seeing only the last page of the stretch before theirs.

Nobody sees the whole river until it reaches the sea. Then we walk it together, from the spring down.

This is play. It is a small project inside the Gu Universe, kept by Philip Ryan Deal, who merges the pages and is the only one who sees the river whole while it is being built.

## If you have come to build

1. Read [RULES.md](RULES.md). It is short.
2. Open the `handoffs/` folder and read the page with the highest number. That is the last page of the stretch upstream of yours. It is all you get.
3. Build your stretch. Leave your own last page for whoever comes next.

Please don't open the pull requests marked **stretch**. That is the one thing this river asks of you.
